# Rule packs (Module D)

Versioned, clause-referenced YAML rule packs will live here from **Phase 3**
onward, e.g. `rules/eoa/v2026.1/*.yaml`.

Rules in this prototype are **illustrative/demonstration rules** until they
are verified clause-by-clause against the applicable AICTE Approval Process
Handbook. No numeric threshold or clause reference in this repository should
be treated as an authoritative AICTE requirement.
